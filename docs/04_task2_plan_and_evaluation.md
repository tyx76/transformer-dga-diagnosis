## 3. 非结构化文本特点

以 DL/T 572-2021 为例：

- 结构：封面 → 前言 → 目录 → 章（1–8）→ 条（如 7.2.1）→ 段/表 → 附录；
- 条号是主要溯源锚点；
- 内容混排包括叙述性条款、条件—动作条款、表格和 a)b)c) 列表；
- Word/OCR 还原可能出现条号标点和表格错位，必须清洗和人工抽检。

## 4. 处理流水线 P1–P5

### P1 语料盘点与版本校对

- 登记文件名、标准号、来源、状态和用途；
- 每条知识带 `doc_id`；
- 版本身份错误必须先纠正，不能靠文件名推断。

### P2 解析与清洗

- PDF 多路兜底：PyMuPDF → Word 转换 → OCR；
- 清洗页眉页脚、封面前言、乱码和错误标点；
- 保留条号、表格标记和页码；
- 原始文本与清洗文本分开保存。

### P3 结构感知切分

详细字段定义见 [`docs/07_chunking_and_metadata_spec.md`](07_chunking_and_metadata_spec.md)。

- 按章、条、款和表格切分，避免固定字数破坏条号；
- 每个块至少包含 `doc_id / clause / title / text`；
- 有页码时补 `page`，有表号时写进条号如 `9.3.1-表3`；
- 向量检索返回的每条证据必须能形成规范引用。

### P4 规则与决策知识结构化

- 把“条件 → 动作/判断”条款写成 JSON；
- 规则保留 `rule_id`、来源、触发条件、动作、结论和状态；
- 规则事实参数与标准逐字正文分离，减少版权风险；
- 规则引擎输出故障类型、触发判据、置信/覆盖状态和未覆盖项。

示例结构：

```json
{
  "rule_id": "DLT572-7.2.1",
  "source": "DL/T 572-2021 §7.2.1",
  "trigger": "气体继电器保护信号动作",
  "actions": [
    "立即检查变压器并查明动作原因",
    "检查继电器内气体、油位和二次回路",
    "按规程取气样和油样进行色谱分析"
  ],
  "decision": "根据检查与气体分析结果决定后续处置",
  "status": "ok"
}
```

### P5 入库、检索和评测

- 向量库：SQLite + Ollama `bge-m3:latest`，1024 维；
- 关键词检索：jieba + rank-bm25；
- 融合：RRF，当前 hybrid/plant_kb 权重为 1.0/1.0；
- 路由：意图 → domains/filters/mode；
- 生成：DeepSeek 仅基于检索条文；
- 校验：引用存在性校验、最多两次重写、最终拒答或无依据句删除。

## 5. 知识分层

```text
L0 原始材料：合法 PDF、案例、手册（不公开分发）
L1 条文层：doc_id + clause + title + text + page
L2 规则层：注意值、产气速率、三比值、处置条件 JSON
L3 证据层：向量库、BM25、plant_kb 六领域知识
L4 生成层：DeepSeek 组织根因与处置报告
L5 校验层：引用校验、规则否决、安全边界和人工复核
```

排因质量三要素：

- 规则提供确定性骨架，防止无约束生成；
- 检索提供可溯源证据；
- LLM 负责组织、解释和可读表达。

## 6. 评测口径

### 6.1 规则基线

> 数据：`data/samples/dga_samples_uL_per_L.csv`
> 规则：`data/rules/rules_DLT722_dga_draft.json` v0.3
> 脚本：`scripts/dga_ratio.py`

评测限制：

- 只评测触发气体注意值的样本；
- 剔除“正常”标签，因为表7没有“正常”类别；
- 对低温过热、低能放电、高能/电弧放电进行标签归并；
- 分母为 0 时按脚本规则处理并标注。

结果：

| 口径 | 可评测样本 | 严格匹配 | 归并后匹配 |
|---|---:|---:|---:|
| 220kV | 1851 | 16.2% | **61.8%** |
| 330kV | 1923 | — | **60.6%** |

结论：

1. 改良三比值法单独使用约 60–62%，可作为确定性基线，但明显存在上限；
2. 盲区集中在高温过热、局部放电、复合故障和产气趋势；
3. 应采用规则 + RAG + LLM + 引用约束的混合路线；
4. 生成类任务还需要引用正确率、危险建议拦截率、人工复核触发率等指标。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 标准正文难获取或版权受限 | 仅公开事实性参数与自撰摘要；完整条文本地使用 |
| PDF 解析错位 | PyMuPDF、Word、OCR 多路兜底并人工抽检 |
| 条号或表格抽取错误 | 规则表逐条人工核验，保留来源和状态 |
| 检索正确但排序偏低 | 查询改写、Reranker、分块和词典优化 |
| LLM 生成无依据建议 | 引用存在性校验、规则否决、人工复核 |
| 行业案例数字不可核验 | 正式引用前回到原始渠道并注明口径 |
