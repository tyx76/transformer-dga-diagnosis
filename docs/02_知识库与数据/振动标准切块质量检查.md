## 6. 最终判断

| 可能原因 | 判断 |
|---|---|
| `4.3` 被切成 4.3.1/4.3.2 碎片 | 否，存在一条完整正确 chunk |

| 切块/条号元数据污染 | 是，存在误挂到 `4.3` 的碎片 |
| domain 过滤 | 是，目标为 generator_electrical，汽轮机查询未实际使用 adjacent domain |
| 术语/语义不匹配 | 是，用户数值型振动描述与标准准则Ⅱ表述差距明显 |
| 排序问题 | 是，BM25 约 233-241，hybrid Top-100 外 |
| 答案生成问题 | 当前阶段尚未进入生成，主要卡在召回和排序 |

**结论：这是“切块元数据有污染 + domain 未真正扩展 + 术语/语义不匹配”的组合问题，不是 `4.3` 内容缺失或被切成多个子条号。**
