# 规则基线评测：改良三比值法（DL/T 722-2014）

> 日期：2026-09-11 ｜ 数据：`data/样本/dga_samples_uL_per_L.csv` ｜ 规则：`data/知识库/rules_DLT722_dga_draft.json` v0.3 ｜ 脚本：`scripts/dga_ratio.py`
> 用途：给“规则基线”一个可复现的数字，作为后续 RAG + LLM 方案的对比基线（考纲要求评测）。

## 1. 评测口径（关键，别省）
- **只评测“气体超注意值”的样本**：表3（变压器/电抗器）注意值 H2 > 150、总烃 > 150、C2H2 > 1（330kV及以上）/ 5（220kV及以下）。未触发注意值时**三比值法不适用**（DL/T 722-2014 §10.2.4 a）。
- **剔除“正常”标签**：三比值判断表（表7）中没有“正常”类别。
- **类别归并**：低温过热（两档）→ 低温过热；低能放电（含兼过热）→ 低能放电；电弧放电（含兼过热）↔ 数据集“高能放电”。
- **分母为 0**：分子也为 0 记为 <0.1；分子 > 0 记为 ≥3（脚本会标注“分母为0”）。

## 2. 结果
### 220kV 口径
- 带标签样本 2910：正常 740（剔除）、未触发注意值 280、未匹配 39 → **可评测 1851 条**
- 严格匹配 **16.2%**（标准细分 9 类 vs 数据集标签口径不同，仅作参考）
- **归并后匹配 61.8%**
- 按类（归并后）：高能放电 **79.1%**｜低温过热 72.4%｜中温过热 66.9%｜低能放电 62.5%｜高温过热 48.7%｜局部放电 44.3%

### 330kV 口径
- 可评测 1923 条，归并后 **60.6%**（各类与 220kV 口径接近）

## 3. 结论（写综述/答辩用）
1. 改良三比值法单独使用准确率约 **60–62%**，与已有文献区间一致——**规则基线可用，但有明显上限**；
2. 盲区集中在**高温过热、局部放电、复合故障**（表7 无“正常”类、未纳入产气速率、无固体绝缘专项判据）；
3. 这正是本项目选择**“规则 + RAG + LLM + 引用约束”混合路线**的依据：规则提供确定性骨架与合规依据，检索/LLM 覆盖规则盲区，评测用同一批样本对比基线；
4. 后续评测还应补充：**引用命中率、危险建议拦截率、人工复核通过率**等合规指标（生成类任务不能只看分类准确率）。
