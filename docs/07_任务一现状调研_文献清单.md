## 阅读策略（怎么写综述）
1. **"有哪些路线"**：A1/A4 + B1（RAG 三范式）+ B2/B3（图谱）→ 对应 docs/03 视角一的 4 条知识注入路线。
2. **"不同方案特点（对比）"**：以 B1/B2/B5/B6 的对比表为骨架，落到 docs/03 的对比矩阵（向量 RAG vs GraphRAG vs 微调 vs 规则混合），每路线 1~2 篇代表作。
3. **"根因分析现状"**：C1（AIOps-LLM 综述分类）+ C2/C3（RCAgent 实证）+ D4（因果图谱增强原因分析）。
4. **"领域怎么落地 + 为什么机理约束必要"**：D 组 5~6 篇 + E 组（传统判据局限）+ B4/F 组（防幻觉与可溯源）。
5. **结论落点**：纯 LLM 幻觉/危险建议（题面警告）→ 需"规则/机理知识约束 + RAG + Agent 编排 + 强制引用"的混合路线（docs/03 B4+C2）→ 引出本方案设计。
