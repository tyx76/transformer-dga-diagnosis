# 意图分类规则表说明

> 文件：`data/rules/intent_rules.json`  
> 日期：2026-09-18  
> 用途：为“规则优先，LLM 兜底”的意图理解模块提供可配置关键词和文档域路由规则。

## 1. 数据来源

规则关键词根据以下现有语料补充：

- `DL/T 722-2014`：乙炔、氢气、甲烷、乙烯、乙烷、总烃、化学式、色谱、溶解气体、产气速率、三比值、注意值、故障类型等。
- `DL/T 572-2021`：油温、顶层油温、油温指示异常、冷却介质温度、冷却系统、冷却装置、冷却器、温度计、负载、过载、油位、油面、通风、散热器、停运、跳闸、着火、爆炸、铭牌、额定电流、额定电压、温度限值等。
- `irrelevant` 使用负向控制词，不来自规程正文，仅用于拦截明显与变压器、DGA、运维和安全无关的问题。
- 化学名称、化学式及验收问题中的查询口语（如“要不要”）作为同义表达保留，目的是覆盖用户实际问法，不属于虚构的规程术语。

`GB 26860-2011` 作为安全操作文档域保留在 `safety_check.modules` 中；当前统一语料尚未包含该标准条文，接入该标准后可直接使用。

## 2. 意图与模块

| 意图 | 文档域 | 关键词数量 |
|---|---|---:|
| `dga_analysis` | DL/T 722-2014 | 25 |
| `oil_temp` | DL/T 572-2021 | 19 |
| `safety_check` | DL/T 572-2021、GB 26860-2011 | 22 |
| `equipment_spec` | DL/T 572-2021、DL/T 722-2014 | 23 |
| `irrelevant` | 不检索 | 20 |

## 3. 优先级

- `irrelevant`：0
- `dga_analysis`：1
- `oil_temp`：1
- `safety_check`：1
- `equipment_spec`：2

`priority` 用于普通冲突排序，数值越大优先级越高。以下显式冲突规则优先于数值优先级：

1. 命中 `irrelevant` 时直接拒答，不检索。
2. 安全动作词与诊断意图同时出现时，优先 `safety_check`。
3. 参数、限值、额定值词与油温词同时出现时，优先 `equipment_spec`。
4. DGA 术语与油温词同时出现时，优先 `dga_analysis`。
5. 没有任何意图命中时，按 `irrelevant` 处理。

## 4. 验收示例

| 问题 | 命中关键词 | 预期意图 |
|---|---|---|
| 乙炔超标怎么处理 | 乙炔 | `dga_analysis` |
| 变压器油温过高怎么处理 | 油温、温度过高 | `oil_temp` |
| 要不要立即停电 | 要不要、立即、停电 | `safety_check` |
| 220kV变压器顶层油温限值 | 220kV、顶层油温、限值 | `equipment_spec` |
| 今天晚饭吃什么 | 吃、晚饭 | `irrelevant` |

## 5. 使用约定

- 规则表只负责“候选意图”和“推荐文档域”，最终路由可以由规则层与后续 LLM 兜底共同确认。
- `irrelevant` 命中后不应调用检索和生成模块。
- `safety_check` 命中后必须保留安全依据和人工复核关口。
- `methods` 不属于本规则表的五个业务意图，不参与默认业务路由。
- 修改关键词或模块时，必须更新本说明并重新执行验收问题。
