## 3. 2026-09-18：RRF 单元验证

人工构造两路各 3 条结果，其中 A/B 重复：

```text
向量：A、B、C
BM25：B、A、D
```

RRF 预期：

- A、B 分数累加；
- A、B 排在前列；
- 相同条号保留向量侧元数据；
- 两路均为空时返回 `[]`。

验证结果：

```text
A：1/(60+1) + 1/(60+2)
B：1/(60+2) + 1/(60+1)
C：1/(60+3)
```

✅ 通过。
