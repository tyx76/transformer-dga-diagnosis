## 3. 结论

### 已解决

- 通用设备问题可以被识别为 `general_plant`，不再全部落入变压器安全/油温类别。
- 通用问题可以调用清洗后的 plant_kb BM25 检索，候选条数稳定为 5。
- 真实生成链路和引用校验全部运行成功，无 API 异常。
- 参考文献中的硬性引用校验没有发现无效条号。

### 尚未通过

- 有来源标注的116题中，来源命中@5为26.72%，说明检索出来的条文经常不是题库标注的正确来源。
- 参考答案关键词覆盖率约 21.79%，生成回答与标准答案差距较大。
- 32 道题直接拒答，主要集中在 plant_kb OCR 噪声较大或没有稳定条号的记录。
- 当前清洗 BM25 能去除图片和 HTML 标签，但不能解决原始 OCR 切块、页码和语义碎片问题。

## 4. 下一步

建议不要直接扩大 138 题的“通过”判定。下一步应：

1. 以 12 个 P0 来源文件为基准重新切块，保留章节、条号、页码和原始行号；
2. 对清洗后的文本建立新的向量库或 BM25 索引，不复用当前基于 OCR 噪声文本的 embedding；
3. 对 `general_plant` 单独设置知识域和引用格式，避免与变压器 DGA 证据混用；
4. 增加来源召回率和答案覆盖率的自动评分，再重新跑 138 题；
5. 在质量未达标前，保持 `KB_BACKUP_FALLBACK` 和 `plant_kb` 的过渡策略，不要把通用 OCR 记录直接并入正式证据链。
