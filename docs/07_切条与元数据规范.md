# 切条与元数据规范（初版 v0.1）

> 日期：2026-09-12 ｜ 适用：DL/T 722-2014、DL/T 572-2021 等规程类语料的切块与入库（主干阶段）
> 关联：docs/04（任务二方案 P3/P5）、docs/05（主干阶段日程）、`data/语料/DLT-722-2014_判据表_blocks.jsonl`

## 1. 目的
让每一条知识块都能**追溯到具体条款**，使检索结果可以直接回答"依据是第几节"，同时避免历史上出现过的切块事故。

## 2. 字段定义

| 字段 | 必填 | 说明 |
|---|---|---|
| `doc_id` | ✅ | 文档标识，白名单：`DL/T 722-2014`、`DL/T 572-2021` |
| `clause` | ✅ | 条号（见第 3 节格式），**不得为空** |
| `title` | ✅ | 该条的标题（如「气体继电器动作的处理」「表3 运行中设备油中溶解气体含量注意值」） |
| `text` | ✅ | 块正文（表格块为结构化后的表格内容） |
| `part` | 条件 | 同一条被拆成多块时必填，取 1、2、3…；只有一块时不写 |
| `section` | 可选 | 所属章节，便于展示（如 `9.3`） |
| `page` | 可选 | 页码；**不填就省略该字段**，不要写 null 或空串 |
| `chunk_id` | 可选 | 唯一编号，建议 `<doc>-<clause>[-p<part>]`，如 `DLT722-9.3.1-表3` |

## 3. 条号（clause）书写规则
统一**半角数字与点号**，不带中文标题（标题放 `title`）：

| 类型 | 写法 | 示例 |
|---|---|---|
| 章 | 章号 | `1`、`7`、`10` |
| 条 | 数字层级 | `9.3.1`、`10.2.1`、`7.2.2` |
| 附录 | `附录X` | `附录B`、`附录D` |
| 附录内条 | `X.Y` | `B.1`、`E.1` |
| 表格（挂在某条下） | `条号-表号` | `9.3.1-表3`、`10.2.1-表6` |
| 表格（跨多节，独立） | 表号 | `表3`、`表7` |

**禁止**：`范围`、`前言`、`0.3`、`8`、`30` 这类裸词或错值；全角逗号「，」写进 `clause`。

## 4. 切分粒度规则
1. **按章 → 条 → 款切**，不按固定字数切。
2. **表格必须独立成块**，且数据来源只能是**已核验的规则库/Excel**（表3/表4/表6/表7），不得从 OCR 正文里取。
3. 条款内的小列表（a/b/c）**随所属条一起**，不单独成块；整条超长时按 `part` 再拆。
4. **不入库**：封面、ICS 页、目次、前言、修订说明、页码/页眉页脚。
5. 同一 `(doc_id, clause)` 允许出现多块，但必须有 `part` 且从 1 起连续。

## 5. 校验规则（写进切块脚本，入库前自动执行）
- `clause` 为空或匹配不上正则 → **直接报错、拒绝入库**（初版向量库的硬伤就是 clause 全空）
  ```
  ^([0-9]+(\.[0-9]+)*|[0-9]+(\.[0-9]+)*-表[0-9]+|表[0-9]+|附录[A-Z]|[A-Z]\.[0-9]+(\.[0-9]+)*)$
  ```
- `doc_id` 不在白名单 → 报错
- `text` 长度：普通条款 20–2000 字；表格块 20–3000 字。过短（切碎）或过长（该再拆）都要报错
- 同一 `(doc_id, clause)` 出现第 2 块却没有 `part` → 报错
- 命中噪声模式（`ICS`、`目次`、`===== 第`、连续页码）→ 拒绝或人工确认
- 文件编码统一 UTF-8；读取兼容 `utf-8-sig`（带 BOM）

## 7. 输出与命名
- 统一输出：`data/语料/clauses.jsonl`（每行一个块，UTF-8）
- 判据表导出：`data/语料/DLT-722-2014_判据表_blocks.jsonl`（已按本规范生成）
- 入库后块数必须与 JSONL 行数一致

## 8. 已踩过的坑（务必避开）
| # | 坑 | 后果 | 规避 |
|---|---|---|---|
| 1 | 扫描件 OCR 的表格直接切块 | 表3 数字变成「乙炔150总烃」，判据不可用 | 表格走规则库/Excel，独立成块 |
| 2 | 建了 `clause` 字段却没赋值 | 检索结果无法标注"第几节"（初版向量库） | 入库前校验 clause 非空 |
| 3 | 按固定字数切块 | 切到目录/前言/半句话，引用不到条款 | 按章→条→款切，封面/目次/前言不入库 |
| 4 | 全角/半角混用（`0，1，2` vs `0,1,2`） | 查询与匹配失败 | clause 与代码统一半角 |
| 5 | 同一条拆多块未标 `part` | 引用重复、排序混乱 | 多块必标 part 且连续 |
| 6 | `page` 字段建了但全空 | 元数据误导，无法定位 | 要么补页码，要么省略字段 |
| 7 | 中文全文检索（unicode61 分词） | 关键词匹配中文命中 0 条 | 关键词兜底用 jieba + BM25，不依赖自带 FTS |
| 8 | 中文路径 + 命令行传参 | 路径乱码、脚本报错 | 用相对路径 + 脚本内 pathlib |
| 9 | 论文混入规程知识库 | 检索被论文段落抢位 | 业务库只放规程/标准/案例 |
| 10 | zip 里残留旧索引目录 | 体积膨胀、误判集合 | 重新导出前清空旧目录，只保留当前 segment |
