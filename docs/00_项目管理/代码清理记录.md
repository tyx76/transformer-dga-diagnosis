## 主链路现状

当前主链路为：

```text
answer
  -> classify_intent
  -> route_intent
  -> hybrid_retrieve
       -> retrieve
       -> bm25_retrieve
       -> rrf_fusion
  -> prioritize_results
  -> generate
  -> verify_citations
```

主链路不再调用：

```text
search_knowledge_base()
merge_with_hybrid()
plant_bm25_retrieve()
```
