## 5. 已知问题分析

### 已知问题 1：统一语料后的跨文档域干扰

**现象**

“乙炔超标怎么处理”的混合检索 Top-5 为：

```text
9.3.1-表3、9.3.2-表4、7.1.6、7.1.5、7.1.8
```

其中 `7.1.6/7.1.5/7.1.8` 来自 DL/T 572 运行维护条款。

**根因**

- BM25 已从 5 条 722 判据扩展到 123 条统一语料；
- 当前没有查询意图路由；
- RRF 对向量和 BM25 等权融合，未按 `doc_id` 过滤；
- BM25 的通用词命中可能把非目标文档推进 Top-5。

**影响**

- DGA 查询的上下文被运维条款占用；
- 增加 Token 消耗；
- 可能影响模型对核心判据的注意力，但当前目标条号仍位于 Top-2。

**建议措施**

1. 增加查询意图分类：DGA 气体分析、油温/冷却、安全操作、无关问题；
2. 按意图限制文档域：DGA 问题优先 DL/T 722，油温问题优先 DL/T 572；
3. 使用加权 RRF，而不是永久等权；
4. 建立针对跨域干扰的评测指标。
