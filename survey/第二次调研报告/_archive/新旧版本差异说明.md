# 新旧版本差异说明

> **当前项目口径（2026-10-03）**：项目主对象已转为“通用电厂设备故障诊断”，覆盖锅炉、汽轮机、发电机及辅机。DGA 仅保留为可选专项、历史技术资产或备用能力，不再作为主链路范围；本文如涉及 DGA，请按专项资料阅读。


> 文档状态：版本说明｜整理更新：2026-09-27。

## 2. 保留内容

- DL/T 722-2014 作为 DGA 第一依据；
- DL/T 572-2021 作为运行与处置边界；
- 未命中拒答、条号引用、人工复核三项底线；
- 规则/机理法作为确定性底座；
- 向量 RAG 作为当前工程起点；
- GraphRAG 和 LoRA 不作为 MVP 主路线。

## 3. 新增判断

1. 行业案例进一步支持“领域知识 + 专用工具 + LLM + 人工复核”的组合路线。
2. 多模态融合分为早期、中期和晚期，本项目近期采用规则与文本证据的晚期协同。
3. 图谱不仅要表达关系，还要表达证据边和适用条件，避免把可达关系误读为因果。
4. RCAgent 的 Controller/Expert、OBSK、JsonRegen 和 TSC 可作为 Agent 工程骨架。
5. 当前系统的主要瓶颈已从召回层转向排序层，Reranker 和查询改写优先于扩大 Top-K。
6. LoRA 适合固定分类、格式和术语适配，不适合频繁改版规程和条号级溯源。

## 4. 未变化的安全边界

- 不自动执行停送电、隔离、检修等高风险操作；
- 不输出没有规程依据的正式结论；
- 不以 LLM 多数投票替代规则和安全校验；
- 不把二手行业效果数字直接作为项目收益承诺。

## 5. 章节结构修订

第二轮报告已按“先判断、后论证、再落地”的顺序重排：

1. 任务背景与边界；
2. 行业现状与实践证据；
3. 技术路线总体比较与选型结论；
4. RAG、Agent、知识图谱、多模态、LoRA 分项论证；
5. 项目当前实现与瓶颈；
6. 推荐架构、实施顺序、评测、风险与结论。

本次修订不改变原有技术结论和项目实测数据，主要解决技术专题顺序分散、选型结论出现较晚的问题。
