## 2. 572 处置规则字段

| 字段 | 说明 |
|---|---|
| `rule_id` | 稳定规则标识，通常与条号对应 |
| `source` | 标准号 + 条号，必须可核验 |
| `trigger` | 触发现象或条件，用于规则匹配 |
| `scope` | 对象范围，如油浸/通用/其他 |
| `content` | 对原文的自撰忠实摘要，不逐字公开标准正文 |
| `actions` | 动作序列 |
| `decision` | 条件到结论的分支 |
| `status` | `ok` 或 `partial` |

## 4. 版权边界

- 规则库不逐字收录标准条文，仅保留规则标识、条号来源和自撰摘要。
- 722 判据库仅保留事实性参数，如注意值、产气速率、比值范围和编码。
- 完整标准正文只在本机合法材料中使用，不进入公开仓库。
- 规则结果只能作为辅助诊断依据，涉及停运、检修和灭火等操作必须人工复核。

## 5. 修改流程

1. 修改规则 JSON；
2. 更新对应来源、状态和版本说明；
3. 运行 `python scripts\dga_ratio.py --eval --voltage 220`；
4. 运行 `python scripts\run_regression.py`；
5. 同步 `docs/01_调研与方案/04_task2_plan_and_evaluation.md`、`docs/00_项目管理/08_acceptance_record.md` 和项目状态中的评测数字。
