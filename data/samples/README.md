# data/samples：公开 DGA 故障样本

> **当前项目口径（2026-10-03）**：项目主对象已转为“通用电厂设备故障诊断”，覆盖锅炉、汽轮机、发电机及辅机。DGA 仅保留为可选专项、历史技术资产或备用能力，不再作为主链路范围；本文如涉及 DGA，请按专项资料阅读。


> 文档状态：现行｜更新：2026-09-27
> 用途：规则基线、闭环样例和检索评测的数值数据，不用于训练大模型。
> 版权说明见 [`NOTICE.md`](../../NOTICE.md)。

## 1. 推荐文件

**推荐使用：`dga_samples_uL_per_L.csv`，共 3466 条，全部统一为 μL/L。**

字段：

```text
source, h2, ch4, c2h6, c2h4, c2h2, co, co2,
scale, source_scale, label_raw, label_std
```

另一文件 `dga_samples.csv` 保留原始多量纲整理结果，仅用于追溯，不应直接与统一量纲结果混用。

## 3. 标签分布

alan456 来源的 `label_std`：

- 正常 740
- 高温过热 662
- 高能放电 458
- 低能放电 396
- 局部放电 232
- 低温过热 229
- 中温过热 193

sguys99 来源的 0/1 标签语义尚未确认，不能直接当作标准故障类型使用。

## 4. 量纲与解析

- alan456 原始单位为 μL/L。
- sguys99 原始为 `log10(μL/L)`，统一脚本按 `10^x` 还原。
- `log10=0` 表示该气体为 0/未测，还原为 0，而不是 1。
- sguys99 的键名解析曾在早期版本出错，统一脚本已修复。
- alan456 原始数据没有 CO/CO2 两列。

## 5. 评测使用注意

1. 规则基线只评测触发注意值的样本，并剔除表7无法映射的“正常”类。
2. 数据集标签体系与 DL/T 722 表7 不完全一致，必须做类别归并并单独说明。
3. 220kV 口径规则归并准确率为 61.8%，330kV 口径为 60.6%。
4. 样本评测结果不能直接等同于真实现场诊断准确率。
5. 与标准判据对照时要注意数据年代、电压等级和样本来源。
